01

LifeOS

↗

LifeOS is a comprehensive personal productivity and growth dashboard built with React 18, TypeScript, and Vite, designed to centralize daily task tracking, journaling, and metrics analytics within a fast-paced, highly responsive user interface. The application features an animated dynamic layout powered by Framer Motion and a global theme store driven by Zustand, ensuring seamless state synchronization and fluid navigation across all devices. By integrating interactive data visualizations through Recharts and custom styled layouts via Tailwind CSS, LifeOS transforms raw productivity metrics into actionable, visually compelling personal growth analytics.

React 18 TypeScript Vite Tailwind CSS Framer Motion Zustand Recharts
